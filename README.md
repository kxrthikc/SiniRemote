# SiniRemote 🎛️

**SiniRemote** is a modern, Material 3 Expressive Android application designed to seamlessly control Sinilink Bluetooth Audio Receivers & Amplifiers (such as XY-AP15H, XY-C50H, XY-AP50H, etc.) with persistent background connections, dynamic media-derived themes, and interactive playback controls.

---

## ✨ Features

- 📶 **Automatic BLE Connection & Persistent Background Service**: Stays connected to your Sinilink receiver even when minimized or swiped away from Recents.
- 🎨 **Material 3 Expressive UI & Dynamic Media Themes**: Automatically extracts dominant colors from your playing music's album art to dynamically tint the entire app and sections.
- 🎵 **Interactive Media Controls & Full-Screen Player**: View album art, track title, artist info, and control playback directly from the app.
- 🎚️ **Equalizer Presets**: Quick switching between Normal, Rock, Pop, Classic, Jazz, and Country EQ presets with optional auto-apply on connect.
- 🔀 **Input Source Selection**: Easily switch between Bluetooth, AUX, USB, TF Card, and PC Audio modes.
- 🔊 **Mute Memory Volume Slider**: Remembers your previous volume level before muting and restores it when unmuted.
- 📳 **Tactile Double-Tick Haptics**: Realistic physics-driven button expansion and double-pulse haptic feedback on every tap.

## 🚀 Installation & Release

Download the latest compiled APK from the [Releases](https://github.com/kxrthikc/SiniRemote/releases) page.

1. Transfer `SiniRemote-v1.0.0.apk` to your Android device.
2. Tap the file to install (allow *"Install from Unknown Sources"* if prompted).
3. Grant **Bluetooth** and **Notification Listener** permissions for full dynamic theme and media controls.

---

## 🛠️ Building from Source

1. Clone this repository:
   ```bash
   git clone https://github.com/kxrthikc/SiniRemote.git
   ```
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Build the debug APK via Terminal:
   ```bash
   ./gradlew assembleDebug
   ```
4. Output APK location: `app/build/outputs/apk/debug/app-debug.apk`
